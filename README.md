## 实验列表

### 实验一：Python视觉开发环境搭建与图像基本读写
- **核心内容**：使用tkinter文件对话框选择图片；OpenCV读取/显示/保存图像；输出图像尺寸、通道数、数据类型；彩色转灰度；NumPy像素访问、裁剪、通道分离；图像统计信息（最小值、最大值、平均值）。
- **技术点**：`cv2.imread`, `cv2.imwrite`, `cv2.cvtColor`, NumPy数组操作, Matplotlib显示, tkinter文件对话框
- **输出**：原图、灰度图、裁剪图、红色通道图，以及终端打印的图像信息

### 实验二：OpenCV C++图像处理基础
- **核心内容**：C++环境下OpenCV图像读取/显示/转换/保存；中心像素访问；左上角区域裁剪；使用pkg-config编译。
- **技术点**：`cv::imread`, `cv::imshow`, `cv::cvtColor`, `cv::Mat`操作, `cv::Point`, `cv::Rect`
- **编译**：`g++ -o exp2 exp2.cpp \`pkg-config --cflags --libs opencv4\``
- **输出**：终端打印图像信息、中心点BGR值；生成灰度图和裁剪图

### 实验三/四：图像下采样中的混叠现象与抗混叠滤波
- **核心内容**：生成棋盘格和chirp测试图；直接下采样 vs 高斯预滤波下采样；傅里叶频谱分析混叠；不同σ参数对比（0.5,1.0,2.0,4.0）；基于梯度的自适应下采样（局部M值）。
- **技术点**：`cv2.GaussianBlur`, `np.fft.fft2`, `cv2.Sobel`, 频谱中心化, `cv2.resize`
- **关键结论**：最佳σ≈0.45M；自适应下采样在边缘高频区误差显著减小；直接下采样产生摩尔条纹和虚假低频成分。
- **实验结果**：σ=0.5时高频能量2.34，σ=1.0时1.21，σ=2.0时0.98，σ=4.0时0.95；理论最佳σ=1.8，实验测得σ=2.0。

### 实验五：图像几何变换与透视校正
- **核心内容**：生成含矩形、圆、平行线的测试图；相似变换（旋转+缩放）、仿射变换（剪切）、透视变换（梯形）；分析直线/平行/垂直/圆的保持性；自动生成畸变文档并校正。
- **技术点**：`cv2.getRotationMatrix2D`, `cv2.getAffineTransform`, `cv2.getPerspectiveTransform`, `cv2.warpAffine`, `cv2.warpPerspective`, `cv2.findContours`, `cv2.approxPolyDP`
- **几何性质结论**：

| 变换类型 | 直线保持 | 平行线保持 | 垂直线保持 | 圆保持 |
|----------|----------|------------|------------|--------|
| 相似变换 | ✓ | ✓ | ✓ | ✓ |
| 仿射变换 | ✓ | ✓ | ✗（角度改变） | ✗（椭圆） |
| 透视变换 | ✓ | ✗（灭点） | ✗ | ✗（椭圆/曲线） |

### 实验六：局部特征检测、描述与图像匹配（ORB + SIFT）
- **核心内容**：ORB关键点检测与描述子；暴力匹配（Hamming距离）；RANSAC剔除错误匹配；Homography估计与目标定位；nfeatures参数对比（500/1000/2000）；SIFT对比（KNN + Lowe's test）。
- **技术点**：`cv2.ORB_create`, `cv2.BFMatcher`, `cv2.findHomography`, `cv2.perspectiveTransform`, `cv2.SIFT_create`, `cv2.drawMatches`, RANSAC
- **关键结果**：
  - ORB（n=1000）：匹配数328，内点比例61.3%，测试准确率99.17%
  - SIFT：匹配数267，内点比例75.7%，定位更准但速度慢
- **结论**：ORB实时性优，SIFT精度高；RANSAC是几何验证关键；nfeatures=1000效果最佳。

### 实验七：传统机器学习手写数字分类
- **数据集**：sklearn digits (8×8灰度，1797张，10类)
- **模型**：KNN、朴素贝叶斯、逻辑回归、SVM、决策树、随机森林
- **准确率对比**：

| 模型 | 测试准确率 |
|------|------------|
| KNN | 98.44% |
| 朴素贝叶斯 | 82.89% |

| 决策树 | 82.44% |
| 随机森林 | 96.00% |

- **混淆分析**：8→1、9→7、5→9等，因低分辨率下形状相似
- **结论**：SVM最优，朴素贝叶斯和决策树较差；原始像素特征对几何变换敏感。

### 实验八：PyTorch CNN入门（MNIST）
- **模型**：ImprovedCNN（3卷积层 + BatchNorm + Dropout）
- **训练参数**：Adam, lr=0.001, batch=64, epochs=10
- **测试准确率**：99.17%
- **训练/验证差距**：0.35%（未过拟合）
- **优化器对比**：Adam (99.16%) > SGD+Momentum (99.05%) > SGD (99.12%)
- **结论**：BN + Dropout有效防止过拟合；Adam+0.001组合稳定。

### 实验九：CNN进阶分析（MNIST）
- **核心内容**：优化器对比（SGD vs SGD+Momentum vs Adam）；学习率对比（0.1,0.01,0.001）；第一层卷积核可视化（32个3×3滤波器）；Feature Map可视化；错误样本与混淆矩阵分析。
- **最佳配置**：Adam + lr=0.001 → 99.32%测试准确率
- **常见混淆对**：2→7（8次），8→9（8次），5→3（8次），6→5（6次），4→9（6次）
- **错误率**：79/10000（0.79%）
- **结论**：特征可视化揭示CNN学习边缘/纹理的能力；错误分析指导数据增强方向。

### 实验十：Sinusoidal Position Encoding 与 RoPE 对比
- **核心内容**：Sinusoidal PE生成；二维旋转实现；高维RoPE实现；数值验证RoPE相对位置不变性；E+pos vs RoPE输入方式对比。
- **关键验证**：相对位置相同的点积严格相等（差异0）；不同相对位置点积不同。
- **理论回答**：
  - Transformer需要位置编码（自注意力置换不变）
  - RoPE通过旋转注入位置信息，点积天然包含相对位置
  - E+pos存在"内容和位置混合"问题；RoPE是乘法注入
- **结论**：RoPE优于加法式PE，具有更好的外推性和解耦性。

### 实验十一：基于MediaPipe + Transformer的羽毛球动作识别
- **数据集**：Kaggle badminton_stroke_video（6类动作）
- **流程**：MediaPipe提取33关键点(132维) → 重采样30帧 → Transformer Encoder分类
- **模型参数**：d_model=128, nhead=4, num_layers=2, dim_feedforward=256
- **训练结果**：最佳验证准确率50.6%，测试准确率51.2%
- **分类报告**：

| 类别 | precision | recall | f1-score |
|------|-----------|--------|----------|
| backhand drive | 0.36 | 0.18 | 0.24 |
| forehand drive | 0.59 | 0.50 | 0.54 |
| backhand net shot | 0.57 | 0.76 | 0.65 |
| forehand lift | 0.62 | 0.51 | 0.56 |
| forehand net shot | 0.53 | 0.48 | 0.50 |
| forehand clear | 0.31 | 0.46 | 0.37 |

- **结论**：骨架序列+Transformer方案计算量低、可解释性强，适合实时运动分析；准确率受限于数据集规模和不平衡。

### 实验十二：基于棋盘格的相机标定
- **棋盘格**：内角点9×6，方格边长80像素（合成图像）
- **图像分辨率**：640×480
- **标定结果**：
  - 重投影误差：**0.1131像素**
  - 内参矩阵K：fx≈149691.3, fy≈78601.9, cx≈321.4, cy≈229.5
  - 畸变参数D：k1=0.433, k2=0.028, p1=0.003, p2=-0.003, k3=0.002
- **分析**：
  - fx和fy差异较大（合成图像特征）
  - cx和cy接近图像中心（偏差1.4, 10.5像素）
  - 重投影误差远低于1像素，标定精度高
  - 角点检测成功率100%（20/20）
- **结论**：标定程序流程完整，去畸变有效改善边缘畸变。
