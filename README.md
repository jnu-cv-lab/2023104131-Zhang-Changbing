### 实验三：图像下采样中的混叠现象与抗混叠滤波

**内容**：
- 生成棋盘格和密集 chirp 测试图
- 对比直接下采样与高斯预滤波下采样（M=2）
- 傅里叶频谱分析，观察混叠折叠
- 固定 M=4，测试 σ=0.5, 1.0, 2.0, 4.0 的高斯滤波效果
- 基于局部梯度的自适应下采样（分块 M=2,3,4）

**关键结果**：
- 直接下采样产生莫尔条纹和虚假低频成分；高斯滤波有效消除混叠但模糊图像
- 最佳 σ≈2.0（理论值 1.8），过大或过小均不利
- 自适应下采样在边缘高频区误差显著减小

**结论**：验证了采样定理，抗混叠滤波的必要性及参数选择原则。

### 实验四：图像几何变换与透视校正

**内容**：
- 生成含矩形、圆、平行水平/垂直线的测试图
- 分别应用相似变换（旋转+缩放）、仿射变换（剪切）、透视变换（梯形）
- 分析各类变换对直线、平行、垂直、圆形的保持情况
- 自动生成带透视畸变的文档图像，检测角点并校正

**几何性质结论**：

| 变换类型 | 直线保持 | 平行线保持 | 垂直线保持 | 圆保持 |
|----------|----------|------------|------------|--------|
| 相似     | 是       | 是         | 是         | 是     |
| 仿射     | 是       | 是         | 否         | 否（椭圆）|
| 透视     | 是       | 否（灭点） | 否         | 否（椭圆/曲线）|

**校正效果**：畸变文档的表格线恢复水平和垂直，文字变形消除。

### 实验五：局部特征检测、描述与图像匹配（ORB + SIFT）

**内容**：
- ORB 特征检测（nfeatures=1000），绘制关键点
- 暴力匹配（Hamming 距离），显示前50对匹配
- RANSAC 估计单应矩阵，剔除错误匹配，计算内点比例
- 将 `box.png` 角点投影到 `box_in_scene.png`，绘制边框
- 参数对比：nfeatures=500,1000,2000
- 选做：SIFT 匹配（KNN + Lowe's test + RANSAC）

**关键结果**：
- ORB（n=1000）：匹配数328，内点比例61.3%，测试准确率99.17%
- 参数对比：n=1000 内点比例最高，n=2000 反而略降
- SIFT：匹配数267，内点比例75.7%，定位更准但速度慢

**结论**：ORB 实时性优，SIFT 精度高；RANSAC 是几何验证的关键。

### 实验六：传统机器学习方法用于手写数字图像分类

**数据集**：sklearn digits（8×8 灰度，1797 张，10 类）  
**模型**：KNN、朴素贝叶斯、逻辑回归、SVM、决策树、随机森林  
**关键结果**：

| 模型            | 测试准确率 |
|----------------|------------|
| KNN            | 98.44%     |
| 朴素贝叶斯     | 82.89%     |
| 逻辑回归       | 96.22%     |
| **SVM**        | **99.11%** |
| 决策树         | 82.44%     |
| 随机森林       | 96.00%     |

**错误分析**：混淆对集中在 (8,1)、(9,7)、(5,9)，因低分辨率下形状相似。

**结论**：SVM 最优，朴素贝叶斯和决策树较差；原始像素特征对形变敏感。

### 实验七：PyTorch 入门与图像分类（MNIST）

**模型**：ImprovedCNN（3 卷积 + BN + Dropout）  
**训练参数**：Adam, lr=0.001, batch=64, epochs=10  
**关键结果**：
- 测试准确率：**99.17%**
- 训练/验证准确率差距：0.35%（未过拟合）
- 优化器对比：Adam (99.16%) > SGD+Momentum (99.05%) > SGD (99.12%)
- 学习率对比：0.001 最佳，0.1 不收敛

**结论**：PyTorch 实现完整流程，Adam+0.001 组合有效，BN+Dropout 防过拟合。

### 实验八：CNN 图像分类进阶分析（MNIST）

**内容**：
- 优化器对比（SGD、SGD+Momentum、Adam）→ Adam 最优
- 学习率对比（0.1, 0.01, 0.001）→ 0.001 最佳
- 第一层卷积核可视化（32 个 3×3 滤波器）→ 出现边缘、纹理模式
- Feature map 可视化 → 不同通道对数字不同区域敏感
- 错误样本分析：79 个错误（0.79%），最常见混淆对 2→7、8→9、5→3
- 混淆矩阵：对角线高亮，2 与 7 混淆最严重（8 次）

**结论**：Adam + lr=0.001 在 MNIST 上表现优异；特征可视化揭示了 CNN 的学习能力；错误分析为数据增强提供方向。
